# Edge architecture reading reference

This annotated bibliography records primary sources checked on 2026-09-29 for graduate-level discussion of Python on WebAssembly (Wasm). The question column identifies each source's contribution; the limit column bounds the inference. Deployment support and packaging versions have their single home in [Edge platforms](edge-platforms.md).

| Source | Question answered | Evidence limit |
|---|---|---|
| Parnas, *On the Criteria To Be Used in Decomposing Systems into Modules* (1972): [publication](https://doi.org/10.1145/361598.361623), [readable copy](https://www.cs.lafayette.edu/~gexia/cs301/resources/parnas.html). | Which changing decisions should a module hide? Contrasts information hiding with decomposition into processing steps. | Design argument and examples; a module boundary does not establish a security boundary. |
| Saltzer and Schroeder, [*The Protection of Information in Computer Systems*](https://web.mit.edu/Saltzer/www/publications/protection/Basic.html) (1975). | Which principles govern authority? Least privilege, complete mediation and fail-safe defaults frame host-interface review. | Architectural guidance, not certification of a particular runtime or deployment. |
| WebAssembly Working Group, [*WebAssembly Specification*, 3.0](https://webassembly.github.io/spec/core/) (2026-09-21 edition). | What are core validation, execution and memory semantics? Establishes the machine whose modules an embedding instantiates. | Specification semantics do not prove an engine implementation correct or exclude microarchitectural leakage. |
| Component Model contributors, [*The WIT text format*](https://github.com/WebAssembly/component-model/blob/a25fc0b372dd21f07f0242c46e98bd0f1ea0c0e1/design/mvp/WIT.md) (2026 snapshot). | How does Wasm Interface Type (WIT) describe typed imports, exports, resources and worlds? | A matching interface type is neither permission to access a service nor proof of its behavior. |
| Component Model contributors, [*Canonical ABI Explainer*](https://github.com/WebAssembly/component-model/blob/a25fc0b372dd21f07f0242c46e98bd0f1ea0c0e1/design/mvp/CanonicalABI.md) (2026 snapshot). | How does the canonical application binary interface (ABI) lift and lower component values through core functions and linear memory? | Informal executable specification; no guarantee of zero copying, bounded allocation or universal implementation support. |
| WebAssembly System Interface (WASI) contributors, [*WASI 0.3 overview*](https://github.com/WebAssembly/WASI/blob/39c11a76958d015ace3f1bf68500057a28c7837f/README.md) (2026 snapshot). | How do native asynchronous futures and streams replace earlier explicit polling interfaces? | Interface definitions do not establish that a provider implements them or grants their capabilities. |
| Watt, [*Mechanising and Verifying the WebAssembly Specification*](https://conrad-watt.github.io/papers/watt2018.pdf) (2018). | What can mechanisation establish? Isabelle formalisation, a type-soundness proof and executable artifacts expose specification issues. | The proof concerns that formalised language; it does not verify today's engines, Python runtime or host bindings. |
| Narayan et al., [*Swivel: Hardening WebAssembly against Spectre*](https://www.usenix.org/conference/usenixsecurity21/presentation/narayan) (2021). | Which compiler and hardware techniques address speculative execution across Wasm isolation boundaries? | Research designs and evaluations are not evidence that every provider deploys them or prevents every side channel. |
| Schwarzl et al., [*Remote-Timer-as-a-Service: Efficient Microarchitectural Leakage in the Cloud with Remote Timers*](https://arxiv.org/abs/2608.17043v1) (2026 preprint). | Can remote timing defeat restricted local clocks? Reports a production Cloudflare attack and coordinated mitigation. | Authors report deployed mitigations; this is neither an unpatched-vulnerability claim nor our independent validation. Preprint evidence remains distinct from peer review. |
| Jangda et al., [*Not So Fast: Analyzing the Performance of WebAssembly vs. Native Code*](https://www.usenix.org/conference/atc19/presentation/jangda) (2019). | How do substantial native workloads expose compiler and execution overheads missed by small benchmarks? | Historical engines and workloads; results do not predict current Python startup, throughput or edge costs. |
| Wasmtime maintainers, [*Guest-controlled resource exhaustion in WASI implementations*, GHSA-852m-cvvp-9p4w](https://github.com/bytecodealliance/wasmtime/security/advisories/GHSA-852m-cvvp-9p4w) (2026). | Why must host allocations and resource handles be bounded alongside guest memory? Fix releases: 24.0.6, 36.0.6, 40.0.4, 41.0.4, 42.0.0. | Backports through 41.x require configuration; 42+ supplies protective defaults for this issue. The advisory concerns availability, not demonstrated arbitrary memory access. |
